## 0. 核心公理

> **「今までも、これからも、説明するもの、たいてい真実は複雑難解」**

作品全体を貫く前提。単純な二項対立・単一の黒幕・綺麗な因果律を安易に置かない。
「わかりやすい説明」より「複雑で捉えきれない実態」を常に優先する。

**実務的な帰結**:世界の存在論的基盤を問う究極の問いは、"答えを取得できる"存在によって即答されうるが、
"答えそのものを書き換えられる"存在がさらに上位にいるため、探求は無限後退に陥る(→ [powers.md](powers.md#73-アノマリー競合問題)）。
この堂々巡りを回避するための作中共通の割り切りが──**「この世界は、イカれている」**。

※ 本作は「現代版聖書」「アンチファンタジー」を謳うが、根底にあるのは作者の「圧倒的な自己満足」と「地続きの現実」という美学。商業化のための表面的な最適化は目的にない。

### 統一原理はある。ただし到達できない

本作に統一原理が**ない**わけではない。あるが、不完全性・定義不可能性・計算不可能性・計算複雑性・初期値鋭敏性・不確定性・非決定性・技術的制約といったあらゆるルートで「限界」に突き当たるため、読者も登場人物も**「現実的に知りえない」**位置に置かれている。
登場人物はそれぞれの行動原理・価値基準に従い、「各々が自分なりの、あるいは誰かの考えた仮説を採用しているだけ」に過ぎない。作中で最も科学的なアプローチを取るANOMATROLの集大成が **「アノマリー学」** であり、これは作中で何度もアップデートされ続けている。

※ ナンセンスに見えて「隠れた整合性」を想起させる、という点がこの作者らしい。

### カオスの許容範囲

本作を読み解く鍵は、**「イカれすぎてて逆に何も起きないこともある」**を許容する程度のカオスさ。
多くのフィクションが前提とする「勧善懲悪」「フェアネス」「最低限の保存則」「カタルシス」「説明」は、本作では全て一蹴されうる(実際に起こるかはさておき、そのポテンシャルが常に残り続ける)。
それどころか、一蹴されるだけでなく **「逆に成し遂げようとする勢力」** がいたり、無関係な出来事がA-Life的に同時多発進行していたりする。

## 1. 世界の性質

- ベースはおおむね現実の地球。ただし超常現象・異能力者が実在する。
- **超常現象の性質**:体系化された「魔法」「神話」ではなく、無秩序に積み重なった野良改造データの集合体に近い。管理者もバランス調整も存在せず、理不尽な強さや矛盾がそのまま放置されている。
- **能力・才能の分布は現実より極端**。格差・不均衡が普通にあり、恵まれた者ばかりではない。一方で、稀に出現する天才・異常者の「上限」が現実離れしている。
- **物語的な均質さを狙わない**。多産多死は常態ではなく、何も起きない年・何も起きない地域・平坦な回も普通に存在する。

### 読解上の最重要注意:サンプリングバイアス

作中で解説・掘り下げられるのは、ほぼ例外なく**バケモノ(エイリアン)層＝上澄みだけ**である。
「この世界の住人全員が突出して賢い」ことを意味しない。凡庸な大多数は背景に厳然と存在しており、単に語られる機会が少ないだけ。

この世界には理論的な能力・知性の上限が存在しないため、無秩序でバランスを一切考慮しない野良サーバー的環境(2B2T的な無法地帯)においては、以下のような層ばかりが目立ち、解説対象に選ばれやすい:

> トップランカー / スピードランナー / チーター / 変態 / 廃人 / 縛りプレイヤー / グリッチ悪用デバッガー / なんならサーバーアドミン

※ 現実世界でも、どんな分野でもトップ層だけを取り上げれば「全員が優秀」に見えるのと同じ理屈。1章の「無秩序な超常」「格差の激しい分布」と矛盾しない。

※ **知性の描写は「結果の後出し」ではない**。ニコの人心掌握、カラスの観察力、トマテスの悪用、ユイトの直観、ケイトの不屈、ジャックの苦痛耐性──いずれも「なぜそうなるのか」がキャラクターの癖・知識・特技から作中情報だけで導出でき、時には思考過程や準備期間そのものが描写される。

### 能力の扱い・命名規則

- 能力者は技名や能力名を**叫ばない**。中二病的な命名をしない。
- 自然発生的に得た能力は、名付けずに現象として調査対象にするか、名付けても素っ気ない(「炎のやつ」「俺のトカゲ」「Incident-01」のような即物的・事務的な呼称)。

### 「異常」の境界は地域に依存する

何を「異常」とみなすかは、その地域の科学的教養・宗教観によって相対的に変わる。

- **古代・宗教**:能力によって発現したクリーチャーが「天使的」に振る舞ったため、それを見た古代人が宗教を作った、という成立過程がある。
- **地域固有の呼称**:局所的・イベント駆動型の能力現象が「錬金術」と呼ばれて定着している地域もある。
- **現代の高教養地域(現代日本相当)**:ほぼ全てのアノマリーが社会に知れ渡っている。
  「空から巨大な手がぶら下がる現象が、また金曜日に現れたらしい」と普通にアナウンスされる。特定エリアに入ると動物が二足歩行で喋り出すため、それがそのまま村の風習になっている場所もある。
- ある説では、論理法則そのもの(排中律のような基礎的原則、物理学の基本原理)すら「何らかの能力が顕現した結果、またはその副作用」とする立場すらある。**世界の土台自体が完全には信頼できない**、という含み。

> **世界観の核心的な一文**
> 「物理どころか論理すら超えうる、際限のない超常のポテンシャルのせいで、極端に多様化した生態系が築かれ、たまたま崩壊していない瞬間を切り取ったのが、この世界」

## 2. 地理

舞台は基本的に地球。過去には(地球外由来と思われる)知的存在が多く活動していた時期があるが、現在は全体として人間側が圧倒している。

互いに**無関係で出所も不明な2つの能力**だけで、地球の物理的土台が規定されている:

1. **異常な巨大さ** ── 何らかの能力の影響で、地球が本来より遥かに大きい。理論上は端(境界)が存在するはずだが実質的に到達不可能で、「地球らしい地形」が無限生成され続けているかのように感じられる規模感。
2. **相対性理論への補正項** ── 起源不明の別の能力により、一般相対性理論に特殊な補正項が加わっている。本来ならブラックホール化してもおかしくない質量を持つ地球が、実際には崩壊しない。

※ 誰かが意図して設計したものではなく、**偶発的な副産物としての巨大地球**。見ず知らずの無関係な2つの能力が偶然重なった結果、宇宙に「巨大な面」(実際は球体だが、その証明は困難)が刻まれている、というイメージ。

- 地域によってランダムな異常が発生することもあるが、**多くの地域ではそうした異常は存在しない**(基本的には平穏な地域の方が多い)。

## 3. 時代・歴史

- **時間軸そのものが不確実**:世界規模のループ、時間跳躍(リープ)、概念操作といった大規模事象が過去に何度も起きている。
- **原因追跡の原理的不可能性**:これらの原因は原理的に遡れない。「何らかの無秩序な力がそれを引き起こした」という以上の情報が存在せず、**因果の起点そのものが不可知**。
- **文明の状態**:近代史〜近未来程度の技術水準の文明が多く現れる。ただし能力の影響で各地域・各集団の成長速度がバラバラで、一様な時代区分は成立しない。
- 世界はリアルタイムに時間が経過する(現実の時間経過と連動して情勢が動く)。

## 4. 社会構造・制度

### 国家という概念の不在

従来的な意味での「国」が存在しない。代わりに **「組織」** がくっついたり、寄生したり、点在したりする形で勢力を構成する。
領土を持つかどうかすら組織次第で、固定的な国境という概念が成立していない。

**成立動機は極めて多様**:実益重視 / 血筋・血統重視 / 職権(地位・権限)重視 / 特定の理念や思想重視。
略奪を主目的とする無法集団もあれば、正規軍を保有する大規模組織もある。現代日本レベルの都市建築・インフラを持つ組織、中央集権的に統治する組織、それらの傘下企業も存在し、階層・規模は一様ではない。

**寿命・継承**:一代限りとは限らず、分裂と共生(合併・吸収に近いもの含む)を繰り返す。世代を超えて形を変えながら存続する組織が多い。

**勢力圏の形態も一様ではない**:単一都市内に複数組織が混在するケース、組織ごとにエリアが明確に分かれる(飛び地的な)ケース、複数組織が複数の領土をまたいで共同運営するケース、すべて起こりうる。土地の奪い合いも発生する。

### 国家なき秩序の実効性

成文化された「国際法」的な概念は存在しないか、少なくとも国家による強制力を持たない。
しかし、**大多数のプレイヤー・組織が慣習的に守っているルールを破ることは、事実上その全員を敵に回す行為に等しい**。相互抑止によって一定の秩序が保たれている。

→ 実例:グレーテルとの無線交渉 [arcs/01-secret-service.md](../arcs/01-secret-service.md)

### 経済

- **通貨は「ノワール」**。物価水準はロシアのルーブル程度の不安定さ。発行できるのは、黒銀のリーダー **クロ** ただ一人(→ [ledger/organizations.md](../ledger/organizations.md))。
- 金融・保険・会計・税務といった通常の制度は、無秩序な超常の存在にもかかわらず普通に機能している。
- アノマリー(異常現象)を収集・研究・管理する専門機関が存在する。少数の特定アノマリーを組み合わせて生成した「ポータル」などを財源とする企業グループ・ホールディングスもある。
- 能力を悪用したインサイダー取引・不動産詐欺、逆に能力を娯楽に転用したマジシャン・道化師も存在する。

### 規模の例外事例(スケール感の目安)

酷い事例では **「半径14光年が丸ごと消滅する」** ような天文学的スケールの破壊が起こる。
この世界の"異常"は地球規模に留まらない。

## 5. キャンディー

この世界でタバコ・酒・麻薬に取って代わった、依存性のある嗜好品。地名「キャンディーロード」の由来でもある。

- **起源**:この世界の「キャンディー」という物質の起源は、**すべてトマテスの能力による**。トマテスの誕生と共に、酒・タバコが自然淘汰されていった(→ [ledger/characters-secret-service.md](../ledger/characters-secret-service.md))。
- **見た目**:多種多様。フルーツを模したもの、ケーキ風、ドクロマークのブランド品、市販のペロペロキャンディ型・キャンディケーン型など。
- **摂取方法**:そのまま食べる、砕いて鼻から吸う、火をつけて炙る、成分を注射する、など用途に応じて何でも可能。
- **効果**:多幸作用や依存性の強度は製品ごとに異なる。アドレナリンをもたらすエピペン的な作用、モルヒネに似た鎮痛作用を持つものもある。
- **判別の困難さ**:見た目だけでの完全な判別は困難。ほとんどが商業生産か、カルテルによる密造(顧客のリピート率向上が目的)。
- **普及率**:地域・文化によって大きく異なる。現在のキャンディーロード市民の場合、約50%は一生口にしたことがない。現実世界で言えば、酒とタバコの中間程度の使用率。
