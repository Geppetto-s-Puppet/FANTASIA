# 超能力の定義と理論

記法は [README](../README.md#記法最重要) を参照。(無印=事実 / `◇`=演出 / `※`=解釈 / `?`=未確定)

## 1. 定義

超能力(魔法・呪術・奇跡・異常など、キャラや組織によって呼び名は違うが、指す実体は同一)とは、

> **「ある条件が揃った時、必ず呼び出される一連の処理」**

規模も構造もバラバラで、公平性・保存則のような統一原理はない。**あらゆるMODを手当たり次第に導入したサーバー**のような状態。この中で、特に普遍的・不変的なものだけが後から「自然科学」として体系化され、世界は(消滅には至らず)暫定的に安定している。

**能力は述語論理として再現性を持つ**。能力によって定義された体質・DNA・"死亡条件"などは、物語的な都合ではなく、常に一貫した論理的帰結として機能する。
→ 実例:[地底のヴァンパイアの全滅](#地底のヴァンパイアの全滅)、ユイトのベクトル演算による条件文([arcs/01-secret-service.md](../arcs/01-secret-service.md))

### 複雑さのスペクトラム

定義そのものは単純だが、個々の作用の複雑さは全く一様ではない:

| 類型 | 例 |
|---|---|
| 直感的な作用 | 前方にテレポートする |
| 抽象的な作用 | ダンバー数に9を足す |
| 複雑な作用 | 会話可能なソックパペットを召喚する |
| 確率的な作用 | 18%の確率でしゃっくりする |
| 観測困難な作用 | 寿命が10ナノ秒縮む |
| 原理的に不可知な作用 | 形式体系に不完全性を付与する |

◇ 「一連の処理」という一行定義のシンプルさと、個々の作用の極端な複雑さ・不可知性を対比させる書き方自体が、[核心公理](world.md#0-核心公理)を理論面から補強している。

### 神秘の脱神秘化

「光輪をつけた翼のある天使」のようなものを見かけても、実体は**「起源不明の、通常の光学に反した、そう振る舞うだけの飛行可能な異常実体」**に過ぎない。
この世界において神話的・宗教的な解釈は、常に後付けの人間側の意味づけであり、現象そのものの説明にはならない。

◇ 天使的存在を「起源不明の異常実体」と言い換える書き方は、読者が神話的語彙で理解しようとする瞬間を、観測的・機械的な語彙に引き戻す一貫した文体戦略。

## 2. 能力に取扱説明書はない

**能力の性質は、能力ごとに固有**。「一般的な性質」というものが存在しない。取り消し可能なもの、不可能なもの、両方がある。

**自分の能力を長らく自覚しないまま過ごすケースが珍しくない**:

| 人物 | 内容 |
|---|---|
| トマテス | 発動条件も意図も不要な完全受動型。自分がキャンディーの起源だと気づくのに長い時間を要した |
| ルイ | 銃を触りだした最近まで、リロード不要能力の存在に気づいていなかった |
| セレスティア | 「一度使うと取り消せない」性質を能力そのものが最初から持っており、制御不能に陥っている |

※ 自分の意志と無関係に働く現象を、自分自身の産物だと認識するまでには時間がかかる。特に受動型において顕著。

### 「何もしていないように見える能力」と世界の安定性

存在しない物理量を扱う / 条件充足が極端に困難 / 常に他の能力と相殺される / パラレルワールドでのみ効果を発揮する──こうした理由で「一見何もしていない」能力も多い。

※ これがむしろ世界の安定性に寄与しているという見方がある。派手な能力だけが世界を構成しているわけではない。

## 3. タブーな用途も平然と開拓される

この世界の能力者は、他フィクションなら"禁じ手"として思いついても実行しないような使い方を、平然と実行する。

- ワープ能力者が、相手の体内に小石をワープさせて血栓を作る(暗殺)。
- 回復魔法使いが、相手の白血球を増殖させまくって白血病にする(治癒能力の悪用)。
- クロが「コピーできないものを作る」能力のブロックチェーン的性質を見抜き、通貨ノワールの発行権を得た。
- ガウロンでは、見た目を自由に変えられる能力者が(中身が男だろうと老婆だろうと)風俗で稼いでいる。

※ 致死性の有無こそ違うが方向性は同じ。**能力は生まれ持った固有の性質である以上、それを本気で手にした人間なら、当然あらゆる方向に開拓・応用しようとする**、という極めてリアルな発想。

◇ この作劇が狙う読者反応は「そんな事出来たのか!?」という驚愕ではなく、**「言われてみれば確かに、そんな使い方もあるなあ」という納得・発見**。

## 4. 能力の"伸びしろ"

**伸びる能力と、伸びない能力の両方が存在する**、という当然の事実がキャラクターごとに描き分けられている。

### 突き詰めて応用している例

| 人物 | 内容 |
|---|---|
| トマテス | 受動的な能力の全容解明 |
| カラス | 鴉のビーコン的発想とヒット&アウェイ戦術 |
| ヒメ | "ギャンビット"戦術(自らの左腕を切り落として至近距離に騎士を生成) |
| ジャック | 検証癖。自分の死体で仕様を試す |
| ケミィ | ジャックのDNA操作を見様見真似で学び、量子的な密度汎関数まで考慮した物質生成へ |
| アイヤ | 露悪さの追求。動機が端から軽薄なため、過程より結果の創造性に比重が置かれる |

### 応用の余地に乏しい"ハズレ能力"の例

| 人物 | 能力 | 限界 |
|---|---|---|
| モア | 『悪魔との取引』 | 印紙代の節約という気休め程度のメリットに留まる |
| パウリ | 月52個の白菜 | 栄養が野菜に偏る / 味は安定だが美味しくはなく商業価値は怪しい / 月1回という周期が運用の困難さに直結 |

### 伸びしろを決めるのは「能力 × 持ち主の資質」

能力に修練の余地があるかは、能力そのものの性質だけでなく、**持ち主の学習力・経験との掛け合わせ**で決まる。

- ジャックの死体改造能力は、普通の人間が持っていても"ぐちゃぐちゃの肉"が出来上がるだけ。圧倒的な学習力と長年の実証実験が噛み合って初めて精密なコントロールが実現している。
- 「火の玉を出す能力」のように、そもそも手動で改変できる部分が乏しい能力は伸びしろも乏しい。
- ケミィの成長も、能力そのものの強化ではなく、**使い方・入力精度・テクニックを実証実験で磨いた**結果。能力には筋肉のような"鍛える"対象がない。

### "ハズレ能力"は運用次第で主役になる

| 人物 | 一見無価値な能力 | 実際の運用 |
|---|---|---|
| ANOMATROLの新人 | 小指を握ると数秒前の光景が見える | 過去改変の実在を示唆する[実証実験](#74-アノマトロルの実証実験)の要となる |
| トーロー | 自分の思考がメッセージウィンドウとして他人に見えてしまう | 手下を統率し、大規模な消滅事件の主犯となる |
| ルイ | 正規の銃火器のリロードが不要になる | 軍人以外にほぼ無意味だが、戦場では決定打になる |

## 5. 未解決問題(ANOMATROL)

超常現象の研究・観測を行う機関ANOMATROLが抱える問題群。

### 5.1 頻出単語問題

異なる超能力同士が、同じ概念(特に**「時間」「座標」**)を条件文や作用として共有することが珍しくない。なぜ特定の概念が多くの能力に採用されやすいのかは未解明。

- **仮説A(API説)**:時空そのものが単体の超能力であり、自発的に他の能力の条件文に絡みついている。
- **仮説B(バイアス説)**:能力自体はあらゆる箇所で繋がっているが大半が検出不能なため、たまたま表出しやすいものだけが観測されている。

### 5.2 出来すぎたエンティティ問題

無駄口を叩くガーゴイル、脅すと言うことを聞くクレイアニメーション風の存在、生きたネズミのように振る舞う金属など、能力によって直接発生する/複数の物理法則を介して自然発生するエンティティ群がいる。
**起源はバラバラで、進化論的な経緯を辿っていないにもかかわらず、人間の文化・言語を読み取り高精度に振る舞う**点が不気味。

- **仮説A(創造者仮説)**:稀にいる汎用性の高い能力者が悪意を持って作成した。
- **仮説B(インスタント仮説)**:条件文の抽象度が上がるほど複雑な事象が発生しやすく、単に違和感のない事例が無視されているだけ。

### 5.3 アノマリー競合問題(ヨジロによる唯一の解明)

相反する超能力が**全く同一のタイミング・優先度レイヤー**で同時発動した場合に何が起きるか、という問題。
通常は後続処理や優先度の高い処理が完遂されるが、完全に同一条件の場合、稀に以下が起きる:

- 対象が非可算実体になる
- 発動者自体が過去から改竄され、存在しなかったことにされる
- ハウスドルフ性が崩壊し、無限長の空間や再帰的な時間が形成される

#### ヨジロの証明

> **「作用の整合性を保つため、現実そのものが、処理に必要な最低限の形で歪む」**

これは物理法則が場当たり的に破綻しているのではなく、**構造として必然的な補正現象**である。
現実のゲージ理論において、内部空間のねじれ(局所対称性の要請)を補正するために場に曲率が生じ、その結果「力」が立ち現れて見えるのと同じ論理構造を持つ。アノマリー競合も同様に、能力同士の内部的な"ねじれ"を解消するため、外側の場──すなわち現実そのもの──に曲率的な歪みが生じる。

作用する次元・適用範囲は現実の物理学・数学をはるかに超えており、作中の天才たちによって発見された定理群は極めて複雑怪奇。しかし根底にある基本思想は、対称性と保存則の対応関係(ネーターの定理)や、力と曲率の等価性(一般相対性理論)と本質的に変わらない。

この種の発見は作中で **「驚愕定理」** と呼ばれる。作中にノーベル賞に相当する制度はないが、実質的にそれに匹敵する権威を持つ。

※ より単純化した核心イメージ:この世界に「なんでもできるボタン」があったとすれば、既存の理論・形式体系・情報のルールがどうなろうと「必ずそれを成し遂げる」ために、現実的整合性が自動的に改変され続ける。**今出来上がっているこの世界自体が、その"副産物"のような位置にある**。

#### 「不可知」ではなく「無限後退」

「原理的に誰も知りえない」という表現は正確ではない。
アノマリーのポテンシャル空間自体が実質無限であるため、**ユートピア**(半径10m以内で神になれる)、**マザーブレイン**(あらゆる質問に正答を返す大都市規模の機械)、**アンデルセン**(神への質問権)などを用いれば、「この世界の存在論的な基盤は何か」という問いに対して原理的には即座に正答を得られる。

問題はその先にある。"神"のさらに上、宇宙の外側を含む**ルート権限そのものを掌握できる存在**(→ニコ)がいる場合、その存在は「答えそのもの」を事後的に書き換えられる。
つまり質問しても、**得られた答えが得られた瞬間には既に真ではなくなっているかもしれない**、という無限後退に陥る。

※ 作中での実務的な回避策は知的な解決ではなく、態度としての割り切り──「この世界は、イカれている」。これ以上の探求は堂々巡りになるため、前提として受け入れて先に進む、という姿勢そのものが、この作品の"空気"を支えている。

#### 例外:カーネルレベルで動作する能力

通常、能力同士が同一のタイミング・優先度レイヤーで衝突すればアノマリー競合が発生し、現実が歪む。
しかし**ゆめひめあめ編のヒロインの能力は、この"レイヤー"そのものの外側、いわばカーネルレベルで動作している**ため、他のアノマリーとの競合が原理的に成立しない。

- ユメが生成したアーティファクト「幸運のバール」をヒロインの延髄に突き刺しても、競合による歪みは一切発生せず、ゴミ同然に無効化された。
- → [arcs/06-yumehimeame.md](../arcs/06-yumehimeame.md)

※ この世界の"能力同士のルール"にすら、例外的に属さない存在がいる。

### 5.4 ANOMATROLの実証実験(過去改変の示唆)

「自分の小指を握ると数秒前の光景が見える」という、戦闘にも生活にも向かない"ハズレ能力"を持つ新人がいた。
ヨジロは彼をスクリーン前に配置し、安全な条件下で**アノマリー競合を意図的に発生させる実験**を行った。

- 結果、新人は**研究者たちの名前・容姿だけが異なる「変な光景」**を目撃し、実験は打ち切られた。
- 別日には「非常に色彩の高い景色」を目撃。ヨジロはこれを一言 **「光速度の上昇」** と評した。

**ヨジロの解釈**:新人の能力が参照する「過去」の定義がより外在的であるため、アノマリー競合によって改変される**前**の、本来の現実を垣間見ることができた。
つまり、こうした改変は宇宙の各地で不規則かつ頻繁に起きており、改変された側の存在は**"抗う隙すら与えられず"消え、代替されている**可能性が高い。

### 5.5 ローズとヨジロの論争(検出可能性の哲学)

**ローズの主張**:「広域すぎるアノマリー摂動は、自然法則の測定誤差や量子の揺らぎと区別がつかない」

**ヨジロの反論**:「区別する方法はある。非決定性の弱点は、"冗談みたいに情報を的中させるアノマリー"の登場によって覆る」
その根拠として、現実の認識論・数学が突き当たる限界を列挙した上で、「いずれも異なる種のアノマリーによって現に破られている」と主張:

| 限界 | 内容 |
|---|---|
| ヒューム | 帰納の限界 |
| ミュンヒハウゼン | 根拠の無限後退 |
| ゲーデル | 不完全性定理 |
| チューリング | 計算可能性の限界 |
| ポアンカレ | 解析の限界 |

※ この論争は、[「論理法則すら能力の副産物かもしれない」](world.md#異常の境界は地域に依存する)という核心設定を、具体的な理論的根拠を伴って補強する。

◇ 実在の哲学者・学説を並べ、それらが全て作中の異常によって破られているとする構成が、設定に理論的重みを持たせている。

## 6. アノマリー摂動と検知の限界

- 多くの組織が **「アノマリーセンサー」** を量産している(→ [ledger/artifacts.md](../ledger/artifacts.md))。
  大量の物質を混ぜた小型回路で、物理現象を再試行し、結果がメモリと整合するか確認する簡素な装置。
- イベント駆動型アノマリー(能力)や、地域・構造物系アノマリー(ゾーン)の検知には有効。
- しかし **「アノマリー摂動」** ── 異常現象本体だけでなく、それに付随する微小な副作用が偶然センサーに干渉し続けることで、検知そのものが遅延・妨害される現象 ── がある。
- ノイズの種類は同定困難で、透磁率のわずかな変化から、原理的な「算術エラー」まで多岐にわたる。あまりに酷い環境下ではセンサー自体が破損する。

**実例**:機動隊が保持していたアノマリーセンサーから蜘蛛の脚が生え始め、小隊を二つ壊滅させた事件。
原因は、センサー内部の**アンチモン原子**が、でたらめな発動アノマリーのターゲットとしてバインドされたこと。

### 検知不能な脅威:超能力を使わない者

ニコの手口は超能力(アノマリー)ではなく**純粋な技術**であるため、アノマリーセンサーを原理的にすり抜ける。

※ 「超能力バトル」が主軸の作品世界において、超能力を一切使わない者が最大級の脅威になりうる、という逆説。

## 7. 象徴的な挿話

この世界の性質を、事件そのものではなく**寓話として**提示する回。

### 地底のヴァンパイアの全滅

地底に生息していたヴァンパイアは、エコロケーション(反響定位)器官が発達していた。
彼らは壁越しに聞こえる人間の会話や、誤って洞窟に差し込んだ光で仲間が焼け死んだ様子から、**「日光を浴びると死ぬ」**という結論に至った。

この推論自体は正しかった。しかし彼らはそこから **「夜間なら安全」** と誤って一般化し、重装備で夜間に地上進出を試みた。
月光の正体が太陽光の反射であることに気づいておらず、結果として壊滅した。

※ 限られた観測(部分的には正しい)から導いた結論が、致命的な誤った一般化につながる。真実の複雑さを甘く見た種族・集団は、**能力の強弱に関わらず**容易に滅びうる。[核心公理](world.md#0-核心公理)の寓話形式での提示。

### 剣聖ムサシの死

「剣聖」と呼ばれ、演武で銃弾を真っ二つにしたこともある刀使い**ムサシ**が、アイヤに"実験"として殺される回。
→ 全文は [arcs/10-side-stories.md](../arcs/10-side-stories.md#剣聖ムサシの回中盤)

**ヴァンパイアの回が「観測と一般化の限界」を示すのに対し、この回は「推理が正しくても救われない」ことを示す。**

- **様式美に付き合う義務は誰にもない。** アイヤはムサシを強さで上回ったのではなく、**距離を保ち続けただけ**。「ちゃんと剣で弾け」という要求は、相手の土俵に上がるフリをしながら、その土俵が成立する条件を一つも与えないという嘲弄。
- **無敗伝説には必ず裏がある。** ムサシの強さは純粋な剣技ではなく、隠していた能力(地面から枝を生やす)に支えられていた。この作品では「剣一本で銃に勝つ」ような説明のつかない神秘は用意されない。
- **正しい推理が、一段上のメタで潰される。** ムサシはMP消費の序列から次の魔法を逆算するという、この世界の標準的な戦闘作法を瀕死の状態で完璧に実行した。**それでも負けた** ── アイヤがワープのマーカーだけを見せ、推理そのものを餌にしたため。
  ※ 敗因はムサシの判断ミスではない。**推理が正しかったこと自体が利用された。**
