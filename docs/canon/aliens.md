# 「エイリアン」(バケモノ)概念

記法は [README](../README.md#記法最重要) を参照。(無印=事実 / `◇`=演出 / `※`=解釈 / `?`=未確定)

---

## 1. 定義

**人の姿・人語を持ちながら、行動原理や価値基準が根本的に異なる存在。**

- SF的な地球外生命体という意味ではなく、この作品独自の用法。「バケモノ」「怪物」と同義で使われることもある。
- 「原理的に異次元の存在」であり、物語(運命という筋書き)を**意図せず**狂わせてしまう。

> **重要:これは読者のための補助線であって、作中の自己認識ではない。**
>
> 「エイリアン」「バケモノ」「怪物」という定義は、作中キャラクターの動線や演出を理解しやすくするための便宜的な"補助線"に過ぎない。
> 作中キャラクターがそれを自覚して発言したり、それに従って行動しているわけではない。
> 読者が「うわ、流石バケモノだ……こんなやり方で、これを乗り切ろうとは。敵も、相手が悪かったな」と感嘆するための表現である。

- 劇的な展開に**常に**怪物がいるわけではない。「その性質上いるパターンが多い」だけ。
- 例外は [3. 物語の外側を認識している者](#3-物語の外側を認識している者) を参照。

## 2. 核心原則:歪みは「副作用」である

エイリアンは、お約束を**「壊そう」とも「従おう」とも思っていない**。
彼らは単に「自分の考えで動いているだけ」であり、その結果として生じる周囲への被害・運命の歪みは、あくまで**副作用**に過ぎない。

動機自体は「飯が食いたい」「世界は平和であってほしい」「なんか面白いことないかな」といった、あくまで本人基準の単純なもの。そこから自分の価値観に従って行動する、いわば **"ランダムウォーク"**。

> ユイト「俺らは行動原理も価値基準も違う生物なんだよね。生存するかは現実の裁量次第」

※ 全エイリアンがいなければ、この作品はありきたりな普通の展開になる。しかしエイリアンの存在によって物語は"歪む"。この歪みは意図的な"型破り"ではなく、それぞれが独立した価値基準で行動した結果の、偶発的な衝突である。

### 「領域」という捉え方

歪みは「たまたまの巡り合わせ」で生じるのではない。
**エイリアンは、登場した瞬間から、自分の周囲に固有の"領域"を生成し続けている。**

- カラスは登場した時点で、独自に**"搾取の領域"**を生成していた(パウリ・リョウトの運命はこの領域に取り込まれて狂った)。
- シークレットサービス(主にトマテス・ユイト主導)は、本来**"便利屋としてどうにかする領域"**を生成するはずだった。
- **2つの独立した領域が接触したことで、どちらとも異なる第三の領域──「大乱闘」──が生まれた。**

つまり歪みの原因は「誰か一人が特別だから」でも「偶然の巡り合わせ」でもなく、
**複数のエイリアンがそれぞれ生成する領域同士が交差すると、必然的に新しい(予測不能な)領域が生まれる**という構造そのものにある。

### 「歪む前の基準線」は存在しない

「カラス登場までは普通の話で、トマテスの介入によって初めて歪んだ」という捉え方は**誤り**。
**カラスという存在自体が、既にその時点で現実を歪めているエイリアン**であり、"歪む前の普通の状態"はそもそも存在しない。

搾取の構造、「彼らはモグラなんかじゃありませんよ」という発言、被害者を"鴨"に分類する体系──これらは既にカラスというエイリアンによる歪みの産物である。
そこにトマテスという別のエイリアンが重なることで、**歪みの上にさらに歪みが積み重なる**。

※ 一般化すると:歪みが一度だけ起きるのではなく、**常に複数のエイリアンが同時多発的に、それぞれ自分の価値基準で現実を歪め続けている**。物語のどの時点を切り取っても、既に何らかのエイリアンの影響下にある。

### 対称性を見出してはならない

エイリアン同士に**上下・対立・善悪といった相対的な構造は存在しない**。

ケイトの"善意"を、ジャックの"合理"やアイヤの"露悪"と**対をなす存在**として位置づけるのは誤り。
それぞれのバケモノは、他者との関係性で意味づけられるのではなく、**単に各々の内面の論理に従っているだけ**であり、それ単独で完結した存在である。

※ 「対称性」を見出そうとするのは、後付けで物語的な構造を探す読み手側の癖であり、この作品の設計思想とは相容れない。

## 3. 物語の外側を認識している者

エイリアンの大半は自らを「エイリアン」と認識していないが、以下の3名は物語の外側に対する態度が明確に異なる。**この3者は互いに別種**である。

### ヒロイン(ゆめひめあめ編) ── 明確な第四の壁の認識

唯一、明確に「第四の壁」を意識し、**カメラに向かって視聴者に語りかける**。
「この世界は"私"を維持するための物語だ」と認識している。

- 能力が物語の"終わり方"そのものに関わる以上、物語の外側(読者の存在)を意識できても整合性が取れる。
- ※ ただし彼女自身、自分の能力の**真の目的**は最後まで誤解していた(→ [arcs/06-yumehimeame.md](../arcs/06-yumehimeame.md))。

### アンデルセン ── 達観、しかし語りかけない

「神への質問権」により、チューリングの停止性問題やP=NP問題などのあらゆる制約を無視して宇宙全体の真理を悟っている。

- 「我々はタンパク質にすぎない」「ある世界(こちらを認識してはいないが、聞けば分かる。ただ気にしていない)からすれば、我々はただの記号・キャラクターにすぎない」と理解している。
- しかしヒロインのように読者に語りかけることはせず、その認識もない。**動機も合理性もないから、していないだけ**。

### ニコ ── 軸そのものが適用されない

アンデルセンに近いが、そもそも**「いかなる動機も、神になる理由として不適切」**とみなしている。
第四の壁や物語という概念自体が、ニコには"関係ない"。

- ニコはニコの論理で宇宙全体を語っているだけであり、理論・公理系・価値基準・宗教・科学・物語・現実・夢のいずれであろうと、「自分が何か、ここが何かは関係ない」──**ただ、成る**。
- ※ ニコの無関心は、ヒロインの第四の壁認識ともアンデルセンの達観とも根本的に性質が異なる。そもそも「意識する/しない」という軸自体がニコには適用されない。

## 4. 「〜の怪物」の二つ名

| 二つ名 | 人物 | 一貫性の中身 |
|---|---|---|
| 善意の怪物 | ケイト | 戦闘・貧困・組織階層・愛国心・社交・暴政・宗教という**あらゆる文脈を貫いて一切例外を作らない** |
| 悪意の怪物 | アイヤ | 「死ぬまでの暇つぶし」としての露悪。動機の開示そのものを無意味化する |
| 合理の怪物 | ジャック | 感情・情緒の完全な欠如。自身の被差別経験すら生物学的・経済学的な当然の帰結として"理解"する |
| 孤独の怪物 | ケミィ | 他者を「無視」か「利用」しかしない。同族を探し続けた末の神格化 |
| 才能の怪物 | ボン | 非能力者でありながら、フィジカルとセンスだけで能力者を圧倒する |

※ ケイトの怪物性は**優しさの総量ではなく、文脈を問わない一貫性**にある。通常のヒーロー的な優しさが"文脈に応じて発揮される美徳"であるのに対し、ケイトの優しさは**"文脈を無視して適用される公理"**であるため、時に場を白けさせたり、危険を招いたりする。
