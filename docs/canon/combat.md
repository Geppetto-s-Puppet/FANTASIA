## 0. トマテスの忠告 ── この世界の戦闘の前提

新人のモアに向けて語られた、この世界で戦うことの定義。

> 「**能力バトルってのは異種格闘で、技術競争だ**」
> 「**敵はお前を待ってはくれない。敵に弱点があるとも限らない。敵が人間かも分からない。それでも、ゲームルールに適応しろ**」
> 「**能力者本人が、自身の能力の細部までを完璧に理解していない、誤解しているケースもある。喰らってみるまでは、ブラックボックスだ**」

この3行が、以下の全ての内容の前提になっている:

| 忠告 | 帰結 |
|---|---|
| 異種格闘・技術競争 | 同じ土俵は存在しない。「能力の格付け」は成立しない → [powers.md](powers.md#2-第一原則能力に共通の概念は存在しない) |
| 敵は待ってくれない / 弱点があるとは限らない | フェアネスもカタルシスも保証されない → [craft.md](craft.md#物語的都合よりルール確率を優先する) |
| 敵が人間かも分からない | ミヤノ、イヌイヌ、出来すぎたエンティティ |
| **本人すら能力を理解していない** | 情報戦は「相手の申告」を信用できない。喰らってから逆算するしかない |

## 1. 情報戦としての能力バトル

**「相手の戦略・能力を的確に把握できる」万能な索敵系能力は超珍しい。**
そのため以下がほぼ前提スキルになっている:

- 状況証拠の積み上げ
- 事前知識
- 牽制と洞察
- リスクヘッジ
- **発動結果から逆算して発動条件を推理する**

→ 逆算の極致:ニコは「近くにあるものが数回爆発する」という一点の観測のみから、敵の人数・性格・生活習慣・今後の行動計画・加勢しうる組織まで組み立てる。しかもこれを**超能力なしの純粋な論理・観察だけで**行う([characters-keyshop.md](../ledger/characters-keyshop.md))。

ただし、それら全てを無に帰す桁外れの理不尽(例:**半径14光年を削除するペットボトル**)も存在し、対策には限界がある。
※ それでも日々の対策が勝率を上げる、という思考自体は否定されない。

### 重宝される能力 / されない能力

**重宝される**:汎用性が高い / 遠距離 / 連発可能 / 味方を巻き込みにくい / 回復 / 日常・市場特化。
**大半の人間が持つのは実用性の低い"ハズレ"能力**。

ただし弱い能力でも、以下によって差を縮める余地はある:

- 他の能力者との協力
- 契約可能な異常存在
- 未知の格闘技
- アーティファクトの獲得

※ ただし文化資本・経済資本・出自による**機会格差も現に存在する**。誰にでも等しく逆転の目があるわけではない。

## 2. 戦闘距離の3パターン

### ① 遠距離必中の即死パターン(稀)

一瞬で決着がつき、目立たず行われることが多いため、作中では稀にしか描かれない。
能力者や仕様が周知されていると、敵組織が事前対策を講じてくる。

### ② 中距離での銃撃戦 + 能力戦(最多)

**作中の過半数を占める。**
市街地という地形と、量産しやすい銃器が広く出回っていることによる**収斂進化的な帰結**。

この距離感で現実的になる戦術:

- 「バリア」「設置型シールド」の照準
- あえて接近して相手に発動条件を満たさせる(**"地雷を踏ませる"**)

### ③ 高機動・高火力の肉弾戦(最少)

近づくだけで頸椎を折れる能力者がいること、そもそも**能力とはエネルギー保存則に穴を開ける行為**である以上、巨大なポテンシャルを持つ相手への接近自体が極めて危険。

**例外**:セーブ&ロード系・時間巻き戻し系・不死系の能力者は、消耗を恐れず単騎特攻する戦術を取ることがあり、これは実際に機能する。

## 3. 全面戦争の凄惨さ

組織間の紛争ではない**全面的な総力戦**は、通常の銃撃戦+αに留まらない。
「レトリックでは済まない」レベルで以下が起こる:

- 空の色が変わる
- 戦場がマネキンで埋め尽くされる
- 日常の理不尽が跳ね上がる

生存に有利なのは再生・残機・時間巻き戻し系だが、これらは単独で戦況を変えるには向いておらず、ピンポイント対策のリスクもある。

→ 実例:第一次ラグナロクで空が"虹色"になる([arcs/02-keyshop.md](../arcs/02-keyshop.md))

◇ 「空が虹色になる」は二重の意味を持つ。①この作品の超能力がデタラメに発動されまくると、悲惨というより滑稽な光景になるというメタファー。②実際に複数の能力が無作為に組み合わさった結果として空の色が変わった、という観測事実。

## 4. 新人研修レベルの実戦知識

多くの組織が新人研修で教える、能力の特性に応じた具体的な戦術:

- ワープ能力者は、小石を敵の背後にワープさせ、脳幹にめり込ませてから離脱する。
- 磁力操作者は、相手がインプラント患者か事前に調べる。
- 見た目だけ怖い無害な能力者は、無害さがバレる前に交渉材料として使う。

---

## 5. 乱入者と規模の振れ幅

通常の作品では考えにくいレベルの実力者・変わり者・規格外の存在が集うため、**戦闘中の第三者乱入も相対的に珍しくない**。

一方で以下も等しく起こる:

- 子供の兄弟げんか程度の規模の衝突
- 絶対的な強者が、現実に見捨てられるようにあっけなく敗北する場面
- 両者が手を出さずに終わる場面

> **核心的な結語**:「理論上なんでもおきうる」「実際なにがおきるか別」──この2つは常にセットで機能する。

## 6. 徒手格闘(CQB)

この世界の格闘技には様々な種類があるが、**人間工学と「世界に常駐する、ちょっとしたイベント駆動型アノマリー」を併発させたスタイル**が主流。

構成要素:コマンドサンボ / クラヴマガ / PTカリ / BJJの寝技 / レスリング / ムエタイの打撃

- **正式名称はなく**、単純に「CQB」「徒手格闘」などと呼ばれる。

### ニルサイト / テラサイト

量子場と人間工学を組み合わせた体術。局所的な気圧のズレと身体の動きで**量子乱数を調整し、"空気"を操る**。
使用者・流派によって効果が異なる。先天的なギフテッドと、後天的に習得する者の両方が存在する。

- **タイガ**(TIGERPANリーダー):先天的なギフテッド。
- **トリキスタン**:後天的に習得。

### 習熟度の目安(偏差値)

武力・人数・環境・超能力を一切使わない場合の純粋な戦績データ。**「グローボール大会」**の記録に基づく。

| 対象 | 偏差値 |
|---|:---:|
| 冥府の一般兵 | 50程度(やや怠惰) |
| CODE隊員 | 60程度 |
| TIGERPANのエリート部隊 | 70程度 |
| ルイ(格闘技術のみ) | 一般兵レベル |

### 最強格

1. **トリキスタン** ── ダントツ。専用の「チャンピオンロード編」が存在するほどの実力者。
2. **カタストロフィ** ── スティグマタの初代リーダー。同率2位は多数存在する。

※ ルイの例が示すように、**乗り物操縦の技量が常軌を逸していても、肉弾戦では等身大に戻る**。万能超人にしない、というバランス感覚が徹底されている。
