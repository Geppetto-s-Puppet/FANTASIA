# クロックワークス編

## ケイト

**ソラ帝国のスラム出身のキレ者。二つ名は「善意の怪物」。** エイリアンの一人。

- **偉業**:のちに**冥府のトップ三人衆(ウォロ・モナ・エンペ)を打倒**し、冥府の寡占・独裁に直接的な終止符を打つ。冥府弱体化の主因ともなる。
- **勇者御一行**:わずか十数名のパーティーのリーダー。作中最大規模の組織である冥府を打倒したことは、革命的な出来事として位置づけられる。
- 編名「クロックワークス」は、**ケイトの能力の他称**に由来する。? 能力そのものの詳細は未開示。

### 人物像

> **どんな殺人鬼や悪人であろうと決して先制攻撃せず、ギリギリまで話し合いをし、命乞いされると普通に許してしまう。**

文字通りの"英雄"。ただし**優しいだけの無能ではなく、咄嗟の判断力に秀でる**。物語が進むにつれて戦闘描写もスピーディー・スタイリッシュになっていく。

**善意の危うさ**:過去に「キャンディーディーラー」を素手の説得で止めようとして**瀕死になった**経験があるほど、善意が既に無計画・自己犠牲的な域に達している。

### 「例外なき一貫性」としての怪物性

- 戦闘中、咳をした敵に「施設内はクーラーが効きすぎて寒いから、外でやりあおう」。
- 万引きした女性に「お金がないと目がくらむよな。大丈夫、君はわざと間違えたんじゃない」。
- 弾切れの敵兵士に「俺を攻撃しないと、君が尻尾切りに遭ってしまう。マガジンを探してくる」(**組織内での立場まで気遣う**)。
- 愛国心の強いガルーシャの会議で、敵組織ティガーパンの捕虜について「でも彼は出自が違うだけで兄弟だろ?」と発言し、場をシラけさせる。
- ごく軽度の陰口・悪口にも「そういうのはよくない。僕はこういう会に参加しない」。
- 暴君に面と向かって「人殺しはいけないことだよ! 今からでも足を洗おう。ちゃんと償って生きていこう!」。
- 教会の神父に「善行はすべきだ、神がいなくても。その本に出てくる救世主はそこを履き違えた」──**信仰にすら善の根拠を委ねない、無条件の倫理観**。

※ ケイトの"怪物"性は優しさの**総量**ではなく、**戦闘・貧困・組織階層・愛国心・社交・暴政・宗教という、あらゆる文脈を貫いて一切例外を作らない一貫性**にある。
通常のヒーロー的な優しさが"文脈に応じて発揮される美徳"であるのに対し、ケイトの優しさは **"文脈を無視して適用される公理"** であるため、時に場を白けさせたり、危険を招いたりする。
※ ケイトを他の幹部(ジャックの"合理"、アイヤの"露悪"など)と**対をなす存在として位置づけるのは誤り**。→ [canon/aliens.md](../canon/aliens.md#対称性を見出してはならない)

# ゆめひめあめ編

## ユメちゃん

**主人公の一人。ふわふわした性格。**

- 物語開始時点では意識はあるが**"廃人"のような状態**にあり、開口一番「死にたい」と口にする。唯一の友人ヒメちゃんに支えられている。
- **能力**:**ランダムなアーティファクトを生成する**。
  - 一見チートだが、**生成物の中身がランダム**であるため、確実性という点ではチートさに欠ける。
  - 一時的なレーダーとしても使える。
  - 生成した主なアーティファクト:**幸運のバール**、**接触した物体を存在ごと消し去るインク**。
- **結末**:実は**生まれた時からヒロインの能力の射程内**におり、一連の冒険・友情・喪失の全てが、ユメを"悲劇のヒロイン"に仕立て上げるための筋書き通りだったことが判明。
  第1話と同じ「死にたい」という台詞と共に自室へ引きこもり、編は**円環構造**で幕を閉じる。→ [arcs/06-yumehimeame.md](../arcs/06-yumehimeame.md)

## ヒメちゃん

**主人公の一人。ポジティブなお嬢様。** ユメちゃんの大親友で、頻繁に彼女を訪ねては励ましたり、旅行やレジャーに誘ったりしている。

### 能力:騎士の生成

> **強くイメージすることで、自身の近くの任意の位置に騎士のようなエンティティを生成・操作する。**

- **同時生成数に原理的上限はない**が、イメージの鮮明さ・持続力という**認知負荷による現実的な限界**がある(通常時で高品質を維持できるのは9体、低品質なら15体程度)。
- **騎士の身体能力は、ヒメからの距離に依存する**:

| 距離 | 能力 |
|---|---|
| 1〜3m | アスリート級 |
| 3〜5m | 若い男性並み |
| それ以上 | 線形に弱まる |
| 15m超 | ただの死体 |

- **決め手**:カズキとの死闘では、**自らの左腕を切り落として**、その左腕を基準に至近距離(眉間からわずか3cm)に騎士を生成する捨て身の一手で勝利する。
- ※ 単なる高飛車なお嬢様キャラではなく、**消耗戦の見切りと致命的な隠し玉を持つ本物の実力者**。ジャックの「自分の死体を賭けに使う」博打と同系統の、"自傷を戦術に組み込む"作劇パターン。
- **最期**:ヒロインとの最終決戦で、アメの死後、**単純な力負けであっけなく死亡**。

## アメちゃん

**主人公の一人。元STELLA隊員、出世してCODE隊員としてヘッドハンティングされた謙虚な実力者。**

- バディ隊員**コカゲ**の失踪をきっかけに、ヒメちゃん・ユメちゃんと合流しトリオを結成する。
- コカゲの消滅事件までは、訓練カリキュラム上での戦闘経験しかなかったが、成績優秀で頭が良く、真面目。

### 能力:水の"ポインター"

> **注視するだけで、一定量以上の水分を含む液体の速度ベクトルを任意に設定できる。**

- コハクの念力に似た"ポインター"型だが、**偶然の類似**であり世界共通の法則ではない。
- **相対座標の指定が不要**(注視するだけ)。
- コハクの能力が"パルスのみ"なのに対し、アメは**パルス的な単発運用に加え、一定領域の速度場を自動更新し続けることも可能** ── 機能面の自由度はアメの方が高い(逆にコハクはエネルギー形態の自由度が高い)。

**日常的な用途**:カップヌードルを早めに温める / ホースの水流を曲げて満遍なく花に水をやる / 傘をささずに雨に濡れない / 零れた油をまとめて缶に流動させる / バーの酒瓶を内部から破裂させる / 波のない湖でのサーフィン / 水飛沫による煙幕代わり。

**戦闘的な用途**:水でトラックを真っ二つにする / 水で爆発の衝撃をガードする / 水で高所へ素早く移動する / 相手を地上で溺死させる / 液体系の能力に対して無双する。

**作中一度きりの用法**:**「降り注ぐ雨を弾丸級の災害に変える」** ── 無差別性を理解した上で、拘束状態にあり、かつ激情に駆られてやむを得ず実行した。

### 人物像

作中屈指のチート能力を持ちながら、**自尊心が低く、これを自分の実力の一部とみなしたくない**と考えている。

- 無礼でも空気が読めないわけでもないが、その暗すぎる性根ゆえに、無自覚に場を盛り下げることがある。
  ※ 東大生が「東大なんて大したことないですよ」と本心で言ってしまい反感を買うのに近い現象。
- ただしユメ・ヒメには真意を理解されており、三人の仲は非常に良い。
  - ヒメの評:「アメちゃんって、結構ナチュラルメイクで地味な恰好してばかりだけど、実はすっぴん一番可愛いんだよね。なんかアメちゃん羨ましいですわ」
  - ユメの評:「お主はね、とても強い子だ」
- ※ ひねくれているのではなく、単に気を遣い、自分を過信せず、ネガティブな可能性を把握しやすいだけの性格。だからこそ勉強もスポーツも本気で向き合ってきた。
  作者の言う[「天才の人生ではなく人間を描く」](../canon/craft.md#描こうとしているのは天才の人生ではなく人間)という方針が、作品屈指のチート能力者においても徹底されている一例。

### 戦闘力と弱点

- 侮ってはいけない、**彼女も紛れもなくバケモノ**。ヒメが苦戦していたカズキの部下たちを、多勢に無勢の状況で「開幕数分」で返り討ちにしている。能力のチート性能だけでなく、計画性・判断力・集中力の高さによる。
- **ランキング**:少なくともゆめひめあめ編の中では**上位10名**にランクインする戦闘力。ただし他編まで含めると比較は非線形になり、ニコやローズ相手には苦しい。
- **弱点**:身も蓋もないが、**"人間の肉体を持つこと"**。編が進むにつれ戦闘経験・能力理解・観察力・反応速度は鍛えられていくが、この作品に登場するバケモノがそもそも規格外すぎる(ホーク、ニコ、ジャック、ルイなど)。
- **最期**:ヒロインとの最終決戦で、ユメを庇おうとした際に**ヒロインに頭を吹き飛ばされ死亡**。

## ヒロイン

**ゆめひめあめ編に登場する謎の女性。真のラスボス。**

- **物語の外側を明確に認識している**唯一の存在。カメラに向かって読者に語りかける。→ [canon/aliens.md](../canon/aliens.md#ヒロインゆめひめあめ編--明確な第四の壁の認識)

### 能力(表向きの理解)

> **主人公補正がかかり、あらゆる展開が"なんだかんだ"でハッピーエンドを迎える。**

**発動条件(3つ)**:
1. そこに、何かしらの舞台が存在すること(絵本でも、ボードでも、"宇宙"でもいい)
2. そこに、たくさんの人物が存在すること
3. そこに、**ヒロイン自身がいること**

※ 条件3が「自分がそこにいること」である以上、この能力は**事実上どこでも常時発動している**に等しい。

**重要な仕様**:ヒロインが把握しているのは、あくまで **"結果の保証"** のみ(例:「どーせ弾は当たらない。当たっても致命傷には至らず、どうにかなる」)。
その保証が**具体的にどんな経路で実現するか**(鼠に当たる/リロード忘れ/ジャムなど)までは、彼女自身も認知していない。

**カーネルレベルで動作する**ため、他のアノマリーとの競合が原理的に成立しない。→ [canon/powers.md](../canon/powers.md#例外カーネルレベルで動作する能力)

### 能力の真相

> **「ヒロインをハッピーエンドにする」能力ではなく、「ユメちゃんをバッドエンドにする」能力だった。**

ヒロイン自身を含む多くの人物を半ば操り人形にし、ユメに小さな幸福を与えた後、一気に絶望へ突き落とすための装置。
**ヒロイン自身もこの真相を最後まで誤解していた。** → [arcs/06-yumehimeame.md](../arcs/06-yumehimeame.md#真相ハッピーエンドの主語)

### 人物像

- 目は、見ているだけで背筋の凍る、**「運命を全て見透かしているような」目**。相手の肉体ではなく**主観的意識そのもの**を見ているかのようで、「貴方を貴方らしくする全てのものについて知りながら」見ているように感じられる。
- 自覚的に能力を悪用し、気になった異性を「略奪」「捨て」「消し」して恋愛ドラマを演出している。
- 大量の死を「勿体ない」の一言で片付け、興が削がれれば恋人すら躊躇なく殺す。
- **追跡者の検知**:「誰かが私のこと追ってそうですねえ♪」と言いながら黒板に適当な文字列を書くと、それが偶然にも敵の名前や位置を"正確に"表してしまう。

◇ 登場時には不協和音のファンファーレ・トランペット・不気味なアンビエント音が流れ、夕焼けが赤く染まる。

## トーロー

**ゆめひめあめ編の中盤のラスボス。消滅事件の主犯。**

- **能力(足枷型)**:**自分の思考がメッセージウィンドウとして他人に見えてしまう。** 小声で話しても、考えている内容がウィンドウにばっちり表示される。諜報・陰謀には致命的。
- しかし**この能力の使い方が非常に上手く**、様々な者を手下にして、そのうち数名の能力を組み合わせることで消滅事件を引き起こしていた。
  ※ 一見致命的な"ハズレ能力"でも、使い方次第で大掛かりな陰謀の主犯格になりうる実例。→ [canon/powers.md](../canon/powers.md#ハズレ能力は運用次第で主役になる)
- **「クォーター鉄橋消滅事件」については無実**。ヒロインの凶行のスケープゴートにされている。
- **最期**:ヒメの騎士に一突きされて死亡。

## カズキ

**賞金稼ぎ/暗殺者。全身包帯だらけの男。**

- **武器「クリスピーブレード」**:カズキの意思により自由に変形する**肉と骨の塊**。
  剣、斧、鎌、鞭、スノーボード、バット、ミキサー、チェンソー、槍、杖(棒高跳び用)、さらには拳銃やグレネードの収納庫にまで変形する。
  - **実態**:見た目はグロテスクで自律しているように見えるが、実際は**カズキ自身の運動器官の延長**に過ぎず、遠隔の感覚器官や自動追跡アルゴリズムは備えていない(目のような意匠は"飾り")。
- **脅威評価**:最も危険=アメ(部下全員で対応)/ 最も貧弱=ユメ(部下一人の生成クリーチャーで十分)/ **最も執着=ヒメ**。
- **最期**:ヒメとの死闘の末に敗死。操縦者を失ったクリスピーブレードは活動を完全停止する。
- **勝率**:ヒメとカズキは実力伯仲だが、**10回試行すれば9回はカズキが勝つ**という力関係だった。今回ヒメに軍配が上がったのは、あらゆる偶然・条件が重なった結果。

## コカゲ

アメちゃんのバディ隊員(CODE所属)。スターダストストリートで失踪する。

- **死因**:意図的な口封じというより、たまたま消滅事件の"プロセス"の目撃者になってしまった不運による。

## リュウセイ

ヒロインの恋人だった男。カフェでの銃撃戦の後、興が削がれたヒロインに喉をフォークで突き刺され殺害される。

> ヒロイン「リセットしましょう。また見つけます。楽しかったですよ、リュウセイさん♪」

# ビューティフルワールド編

## ファウスト

**「ビューティフルワールド事変」の首謀者の一人。**

- **元は演奏家**。しかし能力の使用が一種の"ドーピング"とみなされ、彼の作った曲は「悪魔の効果で魅力的なだけで、音楽理論的には何の価値もない」とインフルエンサーに暴露された過去を持つ。

### 能力:悪魔との契約

> **「悪魔」を召喚し、代償と引き換えにどんな願いでも叶える。**

- **実行コストは、物理的に自力で実行するより"少しコストが高くなる"。**
- コストは一括ではなく時間をかけて返済される場合もある。
  - 例:「2メートル飛ぶ」と願っても、足が千切れるのではなく、2メートル上昇した後、数日間足が痛み続ける、という形で自動設定される。
- **重要な制約**:差し出す代償は必ず**"自分の所有物"**でなければならない。他人のものは消費できず、何も起きないか、そもそも願いを拒否される。
- 回数制限はない。**発話できなくても、血で紙に願いを書けば発動する**(字が汚くても問題ない)。

### 契約履歴

| 願い | 代償 |
|---|---|
| 「この世界を芸術的にしてくれ」 | ドッペルゲンガーの自然発生 |
| 不老不死の獲得 | 来世での多大なるハンデ |
| 「アンチスキルのアンチスキル」を無効化 | 息子や娘の命 |
| 「聞くと死にたくなる旋律」の生成 | 自身の聴覚の永久喪失 |
| 「この世で最も人気のない場所」への緊急ワープ | 永遠に歩けなくなる |

- **トールキン殺害**:トールキンとの仲違い後、そっくりなドッペルゲンガーが来訪したことで人間不信に陥り、**本物のトールキンを殺害**。国際指名手配される。
- **最期**:ワープ先の**エンドロールエアライン**で待機していたアイヤに遭遇し、絶命したと思われる。

## トールキン

**ファウストと共に「ビューティフルワールド事変」を引き起こした人物。**

- **能力**:生まれつき**「自分の身体と共に成長する指輪」**を持つ。
  - **指輪の所持者は「宇宙の所有権」を持つ**とされるが、単体では無価値に等しい。
  - 組み合わせによって**"昇華"される**性質を持つ。
- 効果が分からず、地場の"能力占い"では適当な答えしか返ってこなかったため、大金をはたいてアンデルセンの「能力鑑定」を受け、正体を知る。
- **「昇華」の正体**:ファウストの契約能力と組み合わさることで、**「全宇宙が射程範囲」**という天文学的規模の技になる。
- **最期**:自分そっくりのドッペルゲンガーの出現により人間不信に陥ったファウストに殺害される。

## ヨッシー

コミュニティ41在住と思われる子供。アンデルセンの紙粘土製・太陽を模した仮面を見て「変なお面!」と指摘する。

# 無所属・その他
