# 『永い夢』設定資料

全10編・全999話の群像劇『永い夢』の設定資料リポジトリ。

---

## 記法(最重要)

このリポジトリでは、**「作中で実際に起きたこと」と「それをどう描いたか」と「後から与えた意味づけ」を混ぜない**。
行頭の記号で層を区別する。

| 記号 | 層 | 意味 |
|:---:|---|---|
| (無印) | **事実** | 作中で実際に起きた、あるいは存在するとされること。正史。 |
| `◇` | **演出** | 何が起きたかではなく、**どう描かれたか**。主観フィルタ・メタファー・構成上の仕掛け・語りの技法。 |
| `※` | **解釈** | 作者・読者・整理時の意味づけ。**作中事実ではない**。消しても正史は壊れない。 |
| `?` | **未確定** | 未開示、または要確認。→ [open-questions.md](index/open-questions.md) |

### 使い分けの実例(カラス戦)

```markdown
- カラスは屋内でユイトのレーザーを受け半身を失い、増援を待って時間を稼ごうとする。
- サトルが無言でカラスの脳天を撃ち、射殺する。
  - ◇ シルエットに映る"牙"は、カラスが実際に見た「白すぎる歯」と同値。
    同じ出来事を、客観描写と主観メタファーの二重レイヤーで描いている。
  - ※ カラスは能力や油断で敗れたのではなく、自分の思想の適用対象になったことで死んだ。
    因果応報の演出ではなく、論理的帰結として描かれている。
```

`◇` を消せば「何が起きたか」だけが残る。`※` を消せば「作中の記述」だけが残る。
どちらも**独立して削除・差し替えができる**ことが、この記法の目的。

## 追記ルール(どこに書くか)

情報が3箇所に増殖しないよう、**一次情報の置き場所を1つに固定する**。

| 追記したい内容 | 置き場所 | 他所での扱い |
|---|---|---|
| 誰にでも当てはまる世界のルール | `canon/` | 実例は arcs/ へのリンク1行のみ |
| 人物・組織の恒久的プロフィール(能力仕様・出自・所属・容姿・最期) | `ledger/` | arcs/ では名前をリンクするだけ |
| 出来事(誰が何をしたか、話の流れ) | `arcs/` | ledger/ では1行要約 + リンク |
| 場所・道具・技術 | `ledger/` | 同上 |

**同じ事実を2箇所に書かない。** 書きたくなったら、片方をリンクに置き換える。

### 設定が変わったとき

旧説は残さず、**確定版だけを本文に置く**。
「以前はこう書いていた」という履歴は資料としては不要(誤読の原因になる)。
ただし、**読者や登場人物が誤解しやすい箇所**は、`※` でニュアンスを補う。

## この作品を扱ううえでの前提

- **核心公理**は [canon/world.md](canon/world.md) の冒頭にある。すべてはここから派生する。
- 編は**話数順にブロック分けされていない**。複数の編が並行進行し、話数の中でシャッフルされる。
  → [canon/craft.md](canon/craft.md)、[index/timeline.md](index/timeline.md)
- 解説されるのは基本的に**上澄み(エイリアン層)**であり、この世界の平均像ではない。
  → [canon/aliens.md](canon/aliens.md)
- ある編の結末を、**他の編や作品全体の傾向として一般化してはならない**。
  各編は独立にサンプリングして理解する。
